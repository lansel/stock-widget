# 股票搜索 — 设计文档

日期：2026-11-16　状态：已批准（对话审批，2026-11-17 补充加入列表、移出列表）　规模：小功能

## 意图

挂件目前只能查看手动写进 stocks.txt 的股票。用户有时候只是想临时看一眼某只股票，不想编辑文件、等热更新，也不想把它加入常驻列表。右键菜单打开搜索窗口，搜到后直接复用现有 K 线窗口看图，挂件本身保持不变。

## 目标

- 右键菜单新增「搜索股票…」，打开独立搜索窗口
- 支持按代码、名称、拼音首字母（如 `gzmt`）搜索，输入防抖 300ms
- 结果列表显示名称、代码、类型（股票 / 指数 / ETF / LOF / B 股），只保留沪深市场
- 选中结果后用现有 K 线窗口打开（复用单例、默认分时、可切周期），不写 stocks.txt、不改挂件行列表
- 搜索窗口背景/文字跟随挂件配置，支持热更新
- 零新增第三方依赖、单 exe

## 非目标 / 反目标

- 不做：搜索历史、收藏、全局快捷键、挂件内嵌搜索（加入列表、移出列表见文末补充，已纳入范围）
- 不做：港美股、北交所、可转债的搜索结果（接口本身不覆盖，见数据接口）
- 反目标：改变现有行情轮询、活动感知、拖动、Win+D、双击看图行为；搜索窗口无法输入/抢不到焦点；引入第三方库或运行时

## 约束

- C# 5 / .NET Framework 4.x，用系统自带 csc 编译
- 构建与自测唯一入口：`powershell -ExecutionPolicy Bypass -File build.ps1`
- 腾讯免费接口，无 SLA，秒级延迟
- 搜索窗口是普通可激活窗口；挂件继续 `WS_EX_NOACTIVATE`，挂件本体的焦点/拖动行为不变

## 数据接口（已实测）

`https://smartbox.gtimg.cn/s3/?v=2&q=<URL 编码查询>&t=all`

- 响应形如 `v_hint="sh~600519~\u8d35\u5dde\u8305\u53f0~gzmt~GP-A^sz~...";`
- 条目以 `^` 分隔，字段以 `~` 分隔：市场~代码~名称~拼音~类型；名称是 `\uXXXX` 转义
- 无结果：`v_hint="N"`
- 实测覆盖：A 股（GP-A）、B 股（GP-B）、指数（ZS）、ETF、LOF；市场为 `sh` / `sz`
- 实测不覆盖：北交所（835185、920002 查无结果）、可转债（110059、113050、123220 查无结果）
- 结果可能混入 `jj`（场外基金）、`hk`、`us`：只保留 `sh`/`sz` 且类型在白名单（GP-A、GP-B、ZS、ETF、LOF）内的条目
- 同一查询可能返回相近条目（如 `000001` 同时有上证指数和平安银行），由用户选择，打开时以接口返回的市场前缀为准

## 方案

- **A. 右键菜单 + 独立搜索窗（选定）**：新增菜单项打开普通 Form，输入法和键盘焦点正常；选中后复用 ChartForm。不破坏挂件的纯展示、不抢焦点设计。
- **B. 全局快捷键直接唤出（否决，留作后续）**：更方便，但挂件上无可见入口、热键可能与别的软件冲突、需要新配置项，v1 不做。
- **C. 挂件内嵌搜索框（否决）**：挂件刻意 `WS_EX_NOACTIVATE`，中文输入与焦点处理别扭，且会改变现有拖动/点击语义。
- **数据源**：腾讯 smartbox（选定，与现有行情同源）；东方财富搜索接口（否决，多域名多套解析无收益）；本地静态代码表（否决，数据陈旧且体积大）。

## 已定细节

- **菜单**：右键菜单顺序为「搜索股票…」→ 分隔线 →「退出」；休市日、无 stocks.txt 时入口都可用
- **窗口**：无边框深色，约 360×260（按 DPI 缩放），居中于挂件所在屏幕；不进任务栏/Alt+Tab；标题行含「搜索股票」和 ×，Esc 关闭；单实例，已打开时只置前
- **输入**：打开时输入框自动获得焦点；内容变化后 300ms 发请求，后续输入丢弃旧响应；空输入显示「输入代码、名称或拼音首字母」
- **键盘/鼠标**：↑/↓ 选择，Enter 打开；鼠标单击只选中，双击打开
- **结果行**：名称（过长省略）+ 代码 + 类型文案；最多显示接口返回的前 10 条
- **打开图表**：复用 WidgetForm 现有单例 ChartForm（已打开则切换标的并置前）；symbol 直接使用结果中的「市场前缀+代码」（如 `sh000001` 是上证指数、`sz000001` 是平安银行），不经过 `ToSymbol` 猜测；标题别名传结果名称，首帧就有名字；打开后关闭搜索窗口
- **主题**：背景/文字跟随挂件当前 bgColor/nameColor，配置热更新时同步（与 ChartForm 同路径）
- **错误**：无结果显示「无匹配结果」，请求失败显示「搜索失败，请重试」；不弹对话框、不阻塞挂件
- **文件**：
  - 新增 `src/StockSearchClient.cs`：URL 构造、抓取
  - 新增 `src/StockSearchParser.cs`：纯解析，进自测
  - 新增 `src/SearchForm.cs`：搜索窗口 UI 与交互
  - 修改 `src/WidgetForm.cs`：菜单入口、搜索窗主题同步、带 symbol 的 OpenChart 重载
  - 修改 `build.ps1`：自测源文件清单
  - 修改 `selftest/SelfTest.cs`：解析与 URL 用例
  - 修改 `README.md`：操作说明与已知取舍

## 补充（2026-11-17）：加入列表

用户确认把搜索结果加入挂件列表，数量不限（README 里的“建议 1–5 只”只是建议，不是上限）。

### 目标

- 搜索窗底部「加入列表」「打开图表」两个按钮；选中结果后点击；不设数量上限
- `Enter` / 双击仍打开图表；`Ctrl+Enter` 也可加入
- 加入后搜索窗保持打开，行尾显示「已加入」，方便连续添加
- 写入当前生效的 stocks.txt；文件不存在时创建；由现有 ConfigWatcher 自动热更新
- 按标的去重；已有则提示「已在列表中」，不重复写
- 只写代码、不写别名；代码取最简且无歧义的写法

### 非目标

- 不做批量勾选、列表排序、别名输入（删除见移出列表补充）
- 不改变行情轮询、挂件拖动和 K 线逻辑

### 已定细节

- **窗口**：为容纳底部按钮，搜索窗高度从 260 增加到 300（按 DPI 缩放），列表区域高度基本不变
- **按钮**：底部左侧状态文字，右侧「加入列表」「打开图表」；无选中时提示「先选择一只股票」
- **状态**：已加入列表 / 已在列表中 / 加入失败 / 先选择一只股票
- **写入格式**：裸 6 位代码能还原出同一标的时写裸代码（`600519`、`000001`、`000300`），否则写市场前缀（上证指数写 `sh000001`）；追加一行 + 换行，保留原注释和顺序
- **编码**：追加内容为纯 ASCII，UTF-8 无 BOM 追加，不影响原文件编码
- **去重**：用 `StockList.ToSymbol` 归一化后比较，裸代码、带前缀、`1A0001` 都算同一标的
- **失败**：文件不存在就创建；父目录不存在或写入失败提示「加入失败」
- **热更新**：只写文件，不额外触发刷新，沿用现有配置监听
- **测试**：新增 `StockListWriter` 自测（新建文件、保留内容、无结尾换行、重复、指数歧义、失败路径）

### 验证

- `build.ps1` 全部自测通过（新增 6 项）
- 实测搜索 600519 → 加入列表 → stocks.txt 出现代码、挂件自动多一行
- 同一只再次加入 →「已在列表中」且文件不变
- 选上证指数加入 → 写入 `sh000001`，不写成 `000001`
- 无 stocks.txt 时加入 → 创建文件并生效；断网/只读路径提示「加入失败」

## 补充（2026-11-17）：移出列表

用户确认在挂件股票行上右键移出。

### 目标

- 右键股票行 → 菜单顶部显示「移出列表」；右键空白/空提示/状态点仍是「搜索股票… / 退出」
- 点击后从当前生效的 stocks.txt 删除对应行；现有 ConfigWatcher 自动热更新
- 删除时保留注释、别名、其他行、顺序、文件编码和换行
- 同一标的多行一起删除；不弹确认、不可撤销
- 休市日股票行隐藏，当天没有移出入口

### 非目标

- 不做批量删除、撤销、列表排序、别名编辑
- 不改变行情轮询、拖动和 K 线逻辑

### 已定细节

- **右键目标**：名称/现价/涨跌幅三个标签的 `Tag` 带行代码；右键按下记录目标，空白/提示/状态点清空
- **菜单**：行上顺序「移出列表 / 搜索股票… / 退出」；目标为空时隐藏移出项和其分隔线，保持原两项菜单
- **匹配**：用 `StockList.ToSymbol` 归一化，指数与股票同码（`sh000001` / `sz000001`）不会误删
- **删除方式**：字节级按行过滤，只跳过匹配行；保留 UTF-8 BOM、CRLF/LF 和原文件其他字节
- **失败**：文件不存在、找不到行或写入失败时静默返回；下一次热加载会纠正过期行
- **菜单文案**：固定「移出列表」，当前右键的那一行就是目标

### 验证

- `build.ps1` 新增 6 项自测（保留内容、BOM、无结尾换行、找不到、失败路径、指数/股票同码）
- GUI：右键第二行移出 → 文件删行、挂件少一行；再移出最后一只 → 显示「请编辑 stocks.txt」
- 右键空白提示 → 菜单仍是两项，且高度小于行上菜单
- 先加入指数再加入平安银行，分别移出互不影响
- 断网/只读路径不影响挂件运行
