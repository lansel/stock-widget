# 桌面股票挂件 P0–P2 整理 — 设计文档

日期：2026-10-30　状态：待批准　规模：小改动集（短文档）

## 意图

把代码体检中 P0/P1 的问题一次修掉，并把 P2 的三个体验缺口一起设计进去：断网/陈旧数据不可见、百分比列不对齐、没有退出入口。同时把 `WidgetForm` 里最容易出错的桌面显示状态、配置轮询和行渲染拆成可独立理解的单元。目标是更稳、更可测、更省资源；产品定位不变：零安装、单 exe、桌面常驻、不压应用、不进任务栏。

## 目标

### P0（会直接影响使用）

1. 配置缺失或为空时显示灰色提示，不再是一个空白方块。
2. `nameColor` 修改后立即作用于已有行，无需改股票列表或重启。
3. 按住任意文字区域都能拖动挂件。
4. 行情字段异常不崩 UI；解析失败或渲染异常后 `_fetchBusy` 一定复位。
5. 运行中切换 `hideOnWinD` 时正确显示/隐藏，不残留 TOPMOST 状态。
6. 位置按当前显示器和窗口实际尺寸 clamp；多显示器重启不被拉回主屏，拖到边缘不会只剩 1px。

### P1（资源与健壮性）

1. 配置读取从“每 250ms 全量读文件”改成“只在修改时间/长度变化时读”，并对编辑器保存瞬间的空文件做防抖。
2. 全局键盘钩子只在 `hideOnWinD=true` 时安装，切回默认模式时卸载。
3. 挂件隐藏时暂停行情拉取，恢复显示时立即拉一次。
4. 加系统 DPI 感知和布局缩放，125%/150% 下不再由系统位图拉伸。
5. 二次启动静默退出，与设计文档一致。
6. `stocks.txt` 支持行内 `#` 注释（颜色值 `#RRGGBB` 除外）。

### P2（体验缺口，新增范围）

1. **网络/陈旧提示**：只在数据不新鲜时显示一个很小的橙色圆点，正常时完全不可见；不恢复整行状态角标。
2. **百分比列**：名称列固定宽度、超长省略；百分比列固定宽度、右对齐，两行数字的右边缘对齐。
3. **退出入口**：右键菜单“退出”；这是对“纯展示无交互”的一次有意例外，不做托盘图标、任务栏按钮或常驻关闭按钮。

### 代码整理

- 抽出纯逻辑 `DesktopShowState`、`ConfigWatcher`，以及负责行/空状态/颜色/状态点/拖拽目标的 `RowView`。
- 用现有 `SelfTest` 覆盖这些纯逻辑，减少靠手动试 Win+D、配置热加载和防抖。
- `WidgetForm` 只保留窗口创建、定时器、P/Invoke 执行和组装。

## 非目标 / 反目标

- 不做整行状态角标或“开盘中/午休/已收盘/周末”文字；市场状态仍不显示。
- 不做自绘 UI、托盘图标、全局热键、常驻关闭按钮、设置窗口、节假日日历、数据源切换。
- 右键菜单是唯一新增的点击交互；tooltip 只是被动提示，其他点击/双击行为不变。
- 不改变“零安装、单 exe、纯展示、不压应用、不进任务栏”的定位。
- 不改变配置格式（只增加行内注释识别），不要求迁移；不引入第三方依赖或运行时。
- 反目标（出现即失败）：常驻内存超过 100MB；任务栏/Alt+Tab 出现入口；启动需要 .NET SDK/Electron/Python；新增可见的常驻按钮或状态条。

## 约束

- C# 5 / .NET Framework 4.8：不能用字符串插值、`?.`、`out var`、表达式体等 C# 6+ 语法。
- 源码 UTF-8；`build.ps1` 用 `-codepage:65001`。
- 数据源、配置格式、单实例名称、注册表自启项、位置文件路径保持不变。
- 自测是控制台 `SelfTest.exe`，不引用 WinForms；新增纯逻辑必须能进自测。
- 目标是 Windows 10/11；跨不同 DPI 显示器的完整 Per-Monitor V2 自适应不在本次范围。

## 方案

- **A. 就地修补**：所有修复直接写进 `WidgetForm`，保留现有 Label 结构。diff 最小，但 `WidgetForm` 更长，z-order 和配置轮询仍缠在一起，后续容易复发。
- **B. 修补 + 拆出关键状态（选定）**：抽出 `DesktopShowState`（桌面显示决策，纯逻辑可测）、`ConfigWatcher`（修改时间/防抖/空文件保护，可用临时文件测）、`RowView`（行、空提示、颜色、状态点、拖动目标）；P0/P1 照修，外观只做 P2 的必要调整。
- **C. 自绘 UI 重做**：用一个自绘控件画所有行、提示、状态点和右对齐百分比，拖动和 DPI 一次解决；但视觉层重写、回归面最大，超出本次必要范围。

B 是你在对话中选的方案；P2 是在 B 的骨架上增量，不改变结构。下面第 1–15 节和第 “P2 取舍” 是具体实现提议，属于我的默认判断，不是你逐条确认过的。

## P2 取舍

### 状态提示

- **A. 小圆点（推荐）**：只在网络失败/数据陈旧时出现一个橙色圆点，正常隐藏；位置在右上角，不占行高；鼠标悬停显示“行情未更新”。最小侵入，能区分“收盘但数据正常”和“断网”。
- B. 恢复状态角标：显示“网络异常”等文字；信息更明确，但会重新引入你之前移除的状态行，增加视觉负担。
- C. 降低文字亮度/变色：不用新增控件，但会干扰红涨绿跌的可读性，且不明显。

选 A。市场状态文字仍不恢复；用户通过时间判断收盘，通过圆点判断数据是否新鲜。

### 百分比列

- **A. 固定列宽 + 右对齐（推荐）**：名称列 96（缩放后）、百分比列 70（缩放后），名称超长省略，百分比右对齐；窗口宽度保持 190（缩放后）。
- B. 按最长名称动态调宽：列更贴合内容，但窗口会随名称变化，可能改变锚点位置，和“小挂件”定位冲突。
- C. 保持现状：P2 问题不解决。

选 A。名称省略时用 tooltip 显示全名；百分比右边缘对齐。

### 退出入口

- **A. 右键菜单“退出”（推荐）**：隐藏式入口，不占桌面、不进任务栏/托盘；右键任意行或背景都能打开菜单。这是对“纯展示无交互”的一次有意例外。
- B. 托盘图标：容易发现，但直接违反“不进任务栏/托盘”的定位。
- C. 全局热键/常驻关闭按钮：前者不可发现且可能冲突，后者增加视觉噪音。
- D. 不做：继续用任务管理器退出，保持纯展示。

选 A。菜单只放“退出”，不加“打开配置”（配置本来就是编辑 `stocks.txt` 热加载）。如果你认为纯展示比退出便利更重要，可以只否决这一项，保留状态点和列对齐。

## 已定细节

### 1. 空状态

`RowView` 在无有效股票代码时显示一行灰色提示，而不是空白：

- 文件不存在：`未找到 stocks.txt`
- 文件存在但没有有效代码：`请编辑 stocks.txt`

提示占一行，宽度按窗口内宽，超出省略；提示本身也属于拖动/右键目标。代码恢复后销毁提示、重建行。挂件在空状态下仍然可见、可拖动、可配置颜色。

### 2. 外观热更新

- `RowView.ApplyNameColor(Color)` 只改已有名称 Label 的 `ForeColor`，不重建行。
- `BackColor`、`Opacity` 仍由窗体直接应用。
- 只有代码列表变化时才 `RebuildRows`；仅颜色/透明度/背景变化时不重建。

### 3. 拖动

- 拖动逻辑从 Form 扩展成“窗体 + 所有行 Label + 空提示 Label + 状态点”共用的处理器。
- 用屏幕坐标记录起点（`Control.PointToScreen`），避免鼠标从 Label 移到 Form 或另一 Label 时坐标跳变。
- 按下时对发起控件 `Capture = true`，松开释放；快速拖出挂件边界不会丢 `MouseUp`。
- 松开后按当前显示器工作区和窗口实际尺寸 clamp，再写 `pos.ini`。

### 4. 行情解析与 UI 回调

- `QuoteParser.Parse` 用 `double.TryParse(..., NumberStyles.Float, CultureInfo.InvariantCulture, out ...)` 解析价格、昨收、涨跌幅；字段不足或数值非法时跳过该条，不抛异常。
- 无效条目保留上一次的旧数据（与断网保留旧数据一致），不新增错误行。
- `FetchOnce` 的 UI 回调用 `try/finally` 包住解析/渲染，保证 `_fetchBusy = false`；回调内异常不再向 WinForms 未处理异常冒泡。
- 首次拉取放到窗体的 `Shown` 事件，避免构造期 `BeginInvoke` 在句柄未创建时失败。

### 5. `hideOnWinD` 切换与键盘钩子

- 钩子只在 `hideOnWinD=true` 时安装，切换到 false 时卸载并清空 `_winKeyDown` / `_winDToggle`。
- false → true：若当前是 TOPMOST，先 `HWND_NOTOPMOST` 再 `HWND_BOTTOM`，避免运行中改配置后一直压住应用；重置桌面显示状态。
- true → false：若挂件当前隐藏，立即 `Show` 并恢复行情定时器；重置状态后交给默认桌面逻辑。
- 配置缺失按 `hideOnWinD=false` 处理，因此“删掉配置文件导致挂件再也回不来”的路径被修掉。

### 6. 桌面显示状态机

新增 `DesktopShowState`，纯逻辑，不引用 WinForms：

输入：`HideOnWinD`、`WinDToggled`、`WidgetVisible`、前台窗口类别（桌面/任务栏/应用）、上次应用窗口是否存在/可见/最小化、`LastDesktopShown`。

输出：命令（无动作/隐藏/显示/置顶/压到底）、新的 `LastDesktopShown`、是否清除 Win+D 标志。

规则保持现有行为：

- `hideOnWinD` 且检测到 Win+D：隐藏挂件。
- `hideOnWinD` 且挂件隐藏、前台不是桌面/任务栏：显示挂件。
- 默认模式点任务栏：无动作。
- 默认模式离开桌面：若之前因桌面置顶，降回普通层并压到底。
- 默认模式在桌面：若上次应用仍可见且未最小化（只是点了壁纸），不置顶；否则置顶（若挂件已被 Win+D 隐藏，先显示再置顶）。
- `_lastAppFg` 句柄的更新仍留在 `WidgetForm`，状态机只接收“是否存在/可见/最小化”布尔值。

### 7. 配置监听

新增 `ConfigWatcher`：

- 在现有 250ms 的 `_zTick` 里做轻量轮询：`File.Exists` + `LastWriteTimeUtc` + 长度；只在变化时 `ReadAllText`。
- 返回快照：是否变化、文件是否存在、解析后的 `WidgetSettings`。
- 代码列表从有到空（或文件消失）时防抖 500ms 再应用；期间保留旧行。防抖只针对“变空”，正常改代码/颜色/设置立即应用。
- 启动第一次读取不做防抖：文件缺失或为空立即显示提示。
- 读取失败（被编辑器锁住等）保持上一份配置，下个 tick 重试。
- 已知取舍：同一时间戳分辨率内、长度相同的两次保存可能被漏掉；对 250ms 轮询 + NTFS 时间戳足够，后续需要可换 `FileSystemWatcher`。

配置变化应用顺序：颜色/透明度/背景 → 代码列表/空状态 → `hideOnWinD` 切换 → 必要时立即拉一次行情。代码列表变化导致高度变化后，调用一次 `EnsureOnScreen`。

### 8. 隐藏时暂停行情

- `HideWidget()`：`Hide()` + 停止行情定时器；不清空数据。
- `ShowWidget()`：`Show()` + 启动行情定时器 + 立即 `FetchOnce()`。
- `_zTick` 继续运行，用于检测恢复。
- 行情定时器回调里再加 `if (!Visible) return;` 兜底。

### 9. 位置与多显示器

- `PosConfig.Clamp(Point p, Rectangle area, Size size)` 改为按窗口尺寸 clamp，保证整个窗口在 `area` 内：`x ∈ [Left, Right - width]`，`y ∈ [Top, Bottom - height]`；窗口比区域大时贴左上。
- 启动时先加载配置、完成行布局（确定高度），再读位置并 clamp；默认位置也使用最终尺寸。
- 屏幕选择：`Screen.FromPoint(窗口中心)` 取工作区；保存点在已断开的副屏时回落到最近的屏幕。
- 拖动结束用当前中心所在屏幕 clamp。
- 删除旧的尺寸无关 `Clamp(Point, Rectangle)`，并更新自测。

### 10. DPI

- 新增 `src/app.manifest`，声明 system DPI aware；`build.ps1` 主程序加 `-win32manifest:src\app.manifest`。
- 新增 `UiMetrics`（或 `RowView` 内部字段）：用 `Graphics.FromHwnd(IntPtr.Zero).DpiX / 96f` 取系统缩放，按比例放大宽度、行高、左右/上下边距、名称/百分比列宽、圆角半径、最小高度、默认边距。
- 字体仍用 `Microsoft YaHei UI 10f`（点值随 DPI 渲染），不重复放大。
- 窗体设 `AutoScaleMode = AutoScaleMode.None`，避免 WinForms 自动缩放和手动缩放叠加。
- 已知限制：system DPI aware 只保证启动时那台显示器清晰；把挂件拖到不同 DPI 的显示器时由系统拉伸。完整 Per-Monitor V2 不在本次范围。

### 11. 单实例与注释

- 二次启动直接 `return 0`，不弹 MessageBox。
- `StockList.ParseWidgetSettings` 支持行内 `#` 注释：
  - 整行 `#` 开头仍是注释。
  - 无 `=` 的代码行：截断第一个 `#` 后 Trim，再校验代码。
  - 有 `=` 的设置行：值以 `#` 开头时视为颜色，不截断；否则截断第一个 `#` 并 Trim。
- `ParseFileContent` 改为委托 `ParseWidgetSettings(content).Codes`，删除重复解析逻辑；现有测试保持通过。

### 12. 代码组织与构建

新增：

- `src/DesktopShowState.cs`：纯状态机 + `ForegroundKind` / `DesktopCommand` 枚举。
- `src/ConfigWatcher.cs`：配置快照与防抖。
- `src/RowView.cs`：行 Label、空提示、颜色、状态点、布局、拖动/右键目标集合、tooltip。
- `src/UiMetrics.cs`：DPI 缩放常量（也可并入 `RowView`）。
- `src/app.manifest`：DPI 声明。

修改：

- `WidgetForm.cs`：减负，改为组装 + P/Invoke 执行 + 定时器 + 右键菜单。
- `QuoteParser.cs`：TryParse 防护。
- `PosConfig.cs`：尺寸感知 clamp。
- `StockList.cs`：行内注释 + 解析复用。
- `Program.cs`：静默二次启动。
- `build.ps1`：自测源文件清单加入 `ConfigWatcher.cs`、`DesktopShowState.cs`；主 exe 加 manifest。
- `SelfTest.cs`：新增纯逻辑测试。
- `README.md`：补行内注释说明、空状态提示、状态点、右键退出、DPI/多显示器行为；更新自测数量或去掉固定数字。

### 13. 网络/陈旧提示

- `RowView` 增加一个状态点 Label：文本 `●`，8pt，橙色（建议 `#FFAA3C`），默认 `Visible = false`，位于右上角、不占行高；tooltip 文本“行情未更新”。
- `WidgetForm` 维护 `_stale`：
  - 网络异常、HTTP 成功但解析结果不包含任何当前请求的代码、解析/渲染抛异常 → `_stale = true`。
  - 至少一个当前请求的代码解析成功 → `_stale = false`。
  - 不按时间或交易状态判断，收盘时只要最近一次拉取成功就不显示点。
  - 没有股票代码时强制隐藏点，只显示空状态提示。
- 状态点属于拖动/右键目标；切换代码列表时保留当前 `_stale`，直到下一次拉取更新。
- 不新增“网络异常”文字行，不恢复市场状态文字。

### 14. 百分比列与长名称

- 保持窗口宽度 190（按 DPI 缩放），内容区拆成：
  - 名称列：96（缩放后），`AutoSize = false`，`AutoEllipsis = true`，左对齐、垂直居中。
  - 百分比列：70（缩放后），`AutoSize = false`，`TextAlign = MiddleRight`。
  - 左右边距各 12（缩放后），12 + 96 + 70 + 12 = 190。
- 名称 Label 的 tooltip 显示完整名称；百分比 Label 不设 tooltip。
- 空提示 Label 跨两列（166，缩放后），左对齐、省略。
- 行高仍为 26（缩放后）；Label 高度等于行高，文字垂直居中。
- 不改窗口宽度、不做动态列宽；长名称只省略，不撑宽窗口。

### 15. 退出入口

- `WidgetForm` 创建 `ContextMenuStrip`，只放一个“退出”项；赋给窗体、所有行 Label、空提示和状态点（`RowView` 暴露目标列表）。
- 右键只打开菜单，不触发拖动（拖动只响应左键）。
- 点击“退出”：先按当前屏幕和窗口尺寸 clamp 并保存 `pos.ini`，再 `Close()`；`Dispose` 负责卸载钩子、停掉定时器、释放 Label/tooltip/菜单。
- 不添加“打开 stocks.txt”“重新加载配置”等菜单项；配置仍靠编辑文件热加载。
- 这是唯一新增的点击交互；如果后续认为菜单违反“纯展示”，可以只删这一项，不影响其他 P2 改动。

## 测试与验证

自测新增：

- `QuoteParser`：空价格、非数字涨跌幅、字段不足时不抛异常；有效条目仍能解析。
- `StockList`：行内注释、代码行尾注释、设置行尾注释、`bgColor=#RRGGBB` 不被截断。
- `PosConfig.Clamp`：窗口尺寸参与 clamp；右侧/底部越界；窗口大于区域。
- `ConfigWatcher`：首次读取缺失文件；代码变化立即应用；变空防抖 500ms；防抖期间恢复代码则取消；删除文件后的防抖。
- `DesktopShowState`：Win+D 隐藏、隐藏后应用前台恢复、任务栏无动作、点壁纸不置顶、Win+D 后置顶、离开桌面压到底、`hideOnWinD=false` 不隐藏。

手动验证：

- 删除/清空/清空后恢复 `stocks.txt`，提示与行正常切换，不闪空。
- 只改 `nameColor`，已有行立即换色。
- 在名称和百分比文字上都能拖动；快速拖出屏幕边缘后松开，窗口仍完整可见。
- 运行中把 `hideOnWinD` 从 true 改 false（当前隐藏），挂件回来；false 改 true，挂件不再压住应用。

## 风险与回滚

- DPI 缩放是最大视觉风险：先实现、再在 100%/125%/150% 手动核对；若布局明显变差，回退 manifest 和 `UiMetrics`，保留其余修复。
- 状态机抽取可能改变 Win+D 边界行为：用新增单测 + 手动清单兜底；不一致时以现有行为为准。
- 配置防抖会延迟“用户真的清空文件”的提示最多 500ms，可接受。
- 多显示器 clamp 改变旧位置语义：旧 `pos.ini` 首次启动可能被贴回屏内，符合预期。
- P2 列宽/省略会改变长名称的视觉；状态点和右键菜单是新 UI/交互，若与预期不符可单独回退 P2 项。
- 右键菜单在 `WS_EX_NOACTIVATE` 窗口上的行为需要实机确认；如果菜单无法正常获得焦点或与拖动冲突，回退为不做退出菜单。
- 所有改动仍是一个小改动集；回滚 = revert 本次提交，不涉及数据格式迁移。
