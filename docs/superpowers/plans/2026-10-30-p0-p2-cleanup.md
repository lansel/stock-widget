# 桌面股票挂件 P0–P2 整理 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修掉股票挂件 P0/P1 的稳定性、多显示器、配置热加载、DPI 和资源问题，并实现 P2 的状态点、右对齐百分比列和右键退出。

**Architecture:** 保留单 exe WinForms 结构；把桌面显示决策抽成纯逻辑 `DesktopShowState`，把配置读取抽成带防抖的 `ConfigWatcher`，把行/空提示/状态点/拖动目标收进 `RowView`，`WidgetForm` 只做窗口、定时器、P/Invoke 和组装。纯逻辑用现有 `SelfTest` 验证，UI 用构建 + 手动清单验证。

**Tech Stack:** C# 5、.NET Framework 4.8、系统自带 csc.exe、WinForms、HttpClient、System.Drawing。

**Spec:** `docs/superpowers/specs/2026-10-30-p0-p2-cleanup-design.md`

## Global Constraints

- C# 5：禁用字符串插值、`?.`、`out var`、表达式体等 C# 6+ 语法。
- 源码 UTF-8；`build.ps1` 使用 `-codepage:65001`。
- 保持零第三方依赖、单个 `bin\StockWidget.exe`、不要求安装运行时。
- 数据源、配置格式、Mutex 名 `Local\StockWidget_SingleInstance`、注册表 Run 值名 `StockWidget`、`%APPDATA%\StockWidget\pos.ini` 路径不变。
- 自测是控制台 `SelfTest.exe`，不引用 WinForms；新增纯逻辑必须加入 `build.ps1` 的 selftest 源文件清单。
- 目标是 Windows 10/11；DPI 只做 system DPI aware，不做 Per-Monitor V2。
- P2 只做：橙色陈旧状态点、名称省略 + 百分比右对齐、右键“退出”。不做整行状态角标、托盘图标、全局热键、常驻关闭按钮。

## Review Focus

1. `stocks.txt` 缺失、为空、只有设置行：应显示提示而不是空白；`ConfigWatcher` 测试钉住启动/防抖，Task 4–5 手动验证提示切换。
2. 腾讯响应里价格/涨跌幅为空或非数字：UI 不能抛未处理异常；`QuoteParser` 测试钉住。

- [ ] **Step 2: 实现 ConfigWatcher 并加入构建清单**

实现 `ConfigWatcher`，状态至少包含：

- `_path`
- `_initialized`
- `_lastExists`
- `_lastWriteUtc`
- `_lastLength`
- `_lastSettings`（初始 `new WidgetSettings()`）
- `_pendingEmptySince`、`_pendingEmptyExists`、`_pendingEmptySettings`

`Poll(nowUtc)` 规则：

1. 取 `exists`；存在时取 `LastWriteTimeUtc` + 长度，元数据读取失败则返回 `Changed=false`，保留上一份。
2. `_initialized == false`：读取/解析后立即返回 `Changed=true`（文件缺失也立即返回空设置、`Exists=false`），设置 `_initialized=true`。
3. 元数据未变化：若 `_pendingEmptySince` 已存在且 `nowUtc - _pendingEmptySince >= 500ms`，应用 pending 空设置并返回 `Changed=true`；否则返回 `Changed=false`。
4. 元数据变化且文件存在：读取并解析；读取失败返回 `Changed=false`（不更新元数据，下个 tick 重试）。
   - 解析出代码：取消 pending，立即应用，`Changed=true`。
   - 没有代码：若上一份设置也没有代码，立即应用；若上一份有代码，记录 pending（`_pendingEmptySince=nowUtc`、存在标志、空设置），更新元数据但 `_lastSettings` 保持旧的，返回 `Changed=false`。
5. 元数据变化且文件不存在：同上“没有代码”分支；上一份有代码时防抖 500ms，之后应用 `Exists=false`。
6. 防抖期间文件恢复且解析出代码：取消 pending，立即应用。
7. 返回的 `Settings` 永不为 null；`Changed=false` 时返回 `_lastSettings` 和 `_lastExists`。

把 `"ConfigWatcher.cs"` 加入 `build.ps1` 的 `$selftestSrc` 清单。

- [ ] **Step 2: 实现 DesktopShowState 并加入构建清单**

`Decide` 按 spec 第 6 节实现：

1. 若 `WinDToggled`，`ClearWinDToggle=true`。
2. 若 `HideOnWinD`：
   - `WinDToggled` 时：`WidgetVisible` → `Hide`；无论是否隐藏都直接返回，不要在同一 tick 走恢复显示分支。
   - 否则若 `!WidgetVisible && Foreground != Desktop && Foreground != Taskbar` → `Show`。
   - `LastDesktopShown` 原样返回。
3. 默认模式：
   - `Foreground == Taskbar` → `None`，`LastDesktopShown` 原样。
   - `Foreground != Desktop` → 若 `LastDesktopShown` 则 `DropToBottom` 且 `LastDesktopShown=false`；否则 `None`。
   - `Foreground == Desktop`：若 `LastDesktopShown` → `None`；若 `LastAppExists && LastAppVisible && !LastAppIconic` → `None`；否则 `SetTopMost` 且 `LastDesktopShown=true`。
