# 桌面股票挂件 — 设计文档

日期：2026-10-30　状态：已批准（含 2026-10-30 增补）　规模：小（单文件 C# 工具，短文档）

## 意图

Windows 桌面常驻小挂件：切回桌面即可看到 1–3 只 A 股的名称与实时涨跌幅；打开其他软件时不遮挡（位于窗口下层，非置顶小窗）。纯展示、无交互，换股票靠编辑配置文件。

## 目标

- 桌面可见但不压其他窗口；Win+D 后挂件仍显示（默认模式）
- 每行显示 `名称 +x.xx%`，面积小，红涨绿跌
- 交易时段每 3 秒刷新，非交易时段每 60 秒刷新并标注状态
- 配置文件修改后无需重启，下个刷新周期自动生效
- 零安装：单个 exe（系统自带 csc.exe 编译），开机自启
- （增补）股票代码与设置合并到同一配置文件；配置路径可自定义
- （增补）可选 `hideOnWinD` 模式：Win+D 时隐藏挂件，打开任意软件时自动恢复

## 非目标 / 反目标

- 不做：点击交互、到价预警、K 线、设置界面、超过 3 只的滚动列表
- 反目标（出现即视为失败）：需要用户安装任何运行时（.NET SDK / Electron / Rainmeter / Python）；常驻内存超过 100MB；任务栏或 Alt+Tab 出现入口

## 约束

- 本机：Windows 10/11（build 26200），无 dotnet SDK、无 Python，有 Node 20（仅作参考，不进成品）
- 系统自带 csc.exe 为 C# 5 / .NET Framework 4.x：代码不能用字符串插值、`?.`、expression-bodied 等 C# 6+ 特性
- 数据源：腾讯 `qt.gtimg.cn` 免费行情，逗号分隔批量查询（已验证一请求取回多只），响应 GBK 编码，秒级延迟
- 桌面层：向 Progman 发 `0x052C` 创建 WorkerW，`SetParent` 挂入；若系统行为变化导致失败，降级为普通非置顶窗口（代价：Win+D 时会一起隐藏，可接受）
- 无节假日日历：法定假日若落在工作日会显示"盘中"但数据静止（免费源限制，已知取舍）

## 方案

- **A. C# 单文件 exe（选定，用户拍板）**：csc 编译 WinForms，P/Invoke 挂桌面层，HttpClient 拉行情。小、稳、轻，命中需求。
- B. Electron：样式自由，但 200MB 安装包 + 100–300MB 常驻内存，否决。
- C. PowerShell + WPF 脚本：零安装，但执行策略、闪窗、编码坑多，否决。

## 已定细节（对话中确认或陈述后用户未异议）

- 项目路径：`E:\stock-widget\`，设计文档在 `docs\` 下
- 配置（增补）：单一配置文件合并股票代码与设置——
  - 格式：一行一个 6 位股票代码；`hideOnWinD=true|false` 为设置行；`#` 开头注释；空行忽略
  - 路径查找顺序：① 命令行 `--config <path>` ② exe 同目录 `stocks.txt` ③ 桌面 `stocks.txt`（向后兼容）
  - 市场前缀自动判定（6/9 开头→sh，4/8 开头→bj，其余→sz）；文件缺失或无代码时显示提示
- 布局：默认屏幕右上角，可拖动，位置持久化到 `%APPDATA%\StockWidget\pos.ini`；单实例运行（二次启动静默退出）
- 样式：半透明深色圆角底板，`名称 +x.xx%` 两列对齐；红涨绿跌，平盘灰色；显示状态角标（开盘中/午休/已收盘/周末）
- 刷新节奏：工作日 9:30–11:30、13:00–15:00 每 3 秒；其余每 60 秒
- 窗口行为：`WS_EX_TOOLWINDOW`（不进任务栏、不进 Alt+Tab），不抢焦点；Win11 25H2 上 WorkerW 挂载不被 DWM 合成（已实测），改为普通顶层窗 + 桌面前台检测（Progman/WorkerW/Shell_TrayWnd）时 TOPMOST→NOTOPMOST 拉回最前
- Win+D 模式（增补）：默认 `hideOnWinD=false`（Win+D 时挂件显示在最前）；`hideOnWinD=true` 时用低级键盘钩子（`WH_KEYBOARD_LL`）检测 Win+D → 隐藏挂件，任意软件窗口成为前台 → 自动恢复；手动最小化不触发隐藏
- 自启：首次运行写 `HKCU\...\Run` 键 `StockWidget`；卸载 = 删 exe + 删该注册表键（README 说明）
- （增补 2）基金代码：ETF/LOF 支持，沪 50/51/56/58 前缀→sh，深 15/16 前缀→sz；`ToSymbol` 空串防护；颜色值后的行内注释生效（值内第二个 `#` 起为注释）
- （增补 2）异常兜底：UI/AppDomain 未处理异常记入 `%APPDATA%\StockWidget\error.log`（超 1MB 轮转）后继续运行，不闪退
- （增补 3）发布准备：exe 图标（`scripts/make-icon.mjs` 生成 `src/app.ico`，深色圆角+红绿蜡烛线）+ AssemblyInfo 版本号；`autostart=true|false`（默认 true，false 移除自启项，热生效）；自启项保留 `--config` 参数；`v*` tag 触发 CI 自动挂 GitHub Release
- （增补 4）v1.2.0：行别名（代码后空格跟自定义名，别名优先于服务器名，tooltip 带出代码+服务器名，别名变更热生效）；`showPrice=true` 显示现价列（默认关；UiMetrics.PriceColumnWidth 56×缩放，关闭时布局与 v1.1 逐像素一致）
- （增补 5）v1.3.0：A 股节假日表（`HolidayCalendar`，内置上交所 2026 休市安排共 19 个非周末休市日，调休上班周末仍休市，未覆盖年份无害退化）+ 休市日显示：周末/法定假日隐藏行情行、显示"今日休市"单行（工作日收盘后照常显示当日行情，数据仍 60 秒静默刷新保持就绪，开盘边界由 tick 自动切换）
- 网络异常：保留上次数据，角标提示"网络异常"，不崩溃、不闪退
